Funzionalità

Tutto ciò che serve per gestire i tuoi server, in un'unica finestra

Mirto-Launcher è pensato per chi amministra istanze BridgeLink / Mirth Connect: niente script da ricordare, niente Java da installare.

🔒

Tunnel SSH sicuro

I tunnel locali vengono creati e verificati end-to-end prima del lancio: le connessioni remote restano protette, con scheme HTTPS preservato.

🛡

Credenziali cifrate

Password salvate con AES-GCM e chiave legata alla macchina, custodita nel keyring di sistema: Credential Manager su Windows, Keychain su macOS, java-keyring su Linux.

🌐

Multi-piattaforma

Installer Windows, .deb e AppImage per Linux, DMG per macOS Intel e Apple Silicon. Ogni pacchetto include il runtime Zulu FX 17.

⇄

Export selettivo

Esporta l'intero set di connessioni oppure una singola connessione o un intero gruppo, e importali su un'altra macchina con la stessa facilità.

🔄

Aggiornamenti sotto controllo

Verifica della versione disponibile al lancio, con indicazione precisa di quando c'è una release più recente da scaricare.

▪▪

Console Java integrata

Visualizza in tempo reale il log dell'applicazione Mirth/BridgeLink senza aprire terminali separati: utile per debug e monitoraggio.

🔄

Passi da una versione precedente? Su Windows e Linux la cartella dati (~/.bridgelink-launcher → ~/.mirto-launcher), la chiave di cifratura (.bridgekey → .mirtokey) e l'entry nel keyring vengono migrati automaticamente al primo avvio. Su macOS consulta le istruzioni di upgrade nel README.
